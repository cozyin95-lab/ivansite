# Личный сайт Ивана

React + TypeScript + Tailwind CSS + Framer Motion + Lucide React.

## Запуск

```bash
npm install
npm run dev      # локально, http://localhost:5173
npm run build    # сборка в папку dist
```

Папку `dist` можно загрузить на Netlify.

## Где что менять

- `src/data.ts` — текст «Обо мне», услуги, проекты и ссылки, ссылка на Telegram.
- `public/shots/` — свои скриншоты главных страниц сайтов (имена в `README.txt` внутри папки).
  Если файла нет, превью подгружается как живой скриншот страницы.
